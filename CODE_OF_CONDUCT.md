# Code of conduct

We want this repository to be a respectful, useful place.

**Do**
- Be courteous and assume good faith.
- Give specific, constructive feedback.
- Respect that security work involves sensitive information.

**Don't**
- Harass, insult or discriminate against anyone.
- Post other people's private data, or anything illegal.
- Use issues to request or share help with attacking systems you are not authorized to test.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and may block repeat offenders.

To report a conduct problem, use the contact page on [salisec.ir](https://salisec.ir).
