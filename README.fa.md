## سالی‌سکیور چیست؟

سالی‌سکیور ابزار ارزیابی امنیت وب‌سایت است. دامنه‌ای را که مجوز تست آن را دارید وارد می‌کنید و مجموعه‌ای محدود و کنترل‌شده از **۳۹ بررسی** (۲۰ غیرفعال و ۱۹ فعال) اجرا می‌شود. خروجی:

- **گزارش فنی چندصفحه‌ای** (PDF) شامل یافته‌ها، شواهد، بردار CVSS 3.1، استانداردهای مرتبط و راه‌حل رفع؛
- **گزارش یک‌صفحه‌ای مدیریتی** (PDF) برای مدیران و تصمیم‌گیران؛
- خروجی **JSON** قابل پردازش برای اتصال به سایر سیستم‌ها.

یک **گزارش آزمایشی رایگان** در [salisec.ir](https://salisec.ir) موجود است. این گزارش تعداد کل ضعف‌های پیدا شده را نشان می‌دهد، یک یا دو ضعف را همراه با راه‌حل کامل شرح می‌دهد و بقیه‌ی جزئیات را قفل می‌کند. گزارش کامل، محصول پولی است.

## ویژگی‌ها

| | |
|---|---|
| **دو عمق تست** | اسکن فقط غیرفعال (بدون هیچ پروبی فراتر از مرور عادی، DNS و Certificate Transparency) یا غیرفعال + فعال با پروب‌های محدود و فقط‌تشخیصی. |
| **محدود و قابل‌اعتماد** | هر اسکن سقف زمانی و سقف تعداد درخواست، پرس‌وجوی DNS و حجم پاسخ دارد. اسکن هرگز از کنترل خارج نمی‌شود. |
| **پوشش صادقانه** | بررسی‌های ردشده، ناموفق و تایم‌اوت‌شده در گزارش آمده‌اند. «پیدا نشد» هرگز با «تست نشد» اشتباه گرفته نمی‌شود. |
| **امتیازدهی شفاف** | امتیاز CVSS 3.1 از روی بردار چاپ‌شده کنار هر یافته محاسبه می‌شود و با ماشین‌حساب FIRST قابل بررسی است. |
| **اولویت مبتنی بر شواهد** | اولویت P0 تا P4 جدا از شدت است و یافته‌ی تأییدشده را بالاتر از شاخص تأییدنشده با CVSS برابر قرار می‌دهد. |
| **بدون بهره‌برداری** | فقط تشخیص. بدون brute force، بدون credential stuffing، بدون پی‌لود مخرب، بدون آپلود فایل و بدون اجرای اکسپلویت. |
| **برچسب استاندارد** | CWE و OWASP Top 10 (2021) و ارجاع‌های WSTG و ASVS (با بهترین تلاش). |

## انواع اسکن

| اسکن | نام | عمق | سقف زمان | خروجی |
|---|---|---|---|---|
| ۱ | عمومی | فقط غیرفعال | ۲ دقیقه | گزارش فنی کامل |
| ۲ | استاندارد | غیرفعال + فعال | ۶ دقیقه | گزارش پیش‌نمایش (دمو / آزمایشی) |
| ۳ | عمیق | غیرفعال + فعال با بودجه‌ی بزرگ‌تر | ۱۲ دقیقه | گزارش فنی کامل + گزارش یک‌صفحه‌ای مدیریتی |

جزئیات: [docs/scan-profiles.md](docs/scan-profiles.md) (انگلیسی)

## چه چیزهایی بررسی می‌شود؟

TLS و گواهی‌ها · هدرهای امنیتی HTTP، کوکی‌ها، CSP و CORS · DNS و SPF و DKIM و DMARC و CAA و DNSSEC · شناسایی فناوری‌ها و یادداشت‌های آفلاین CPE/CVE · robots.txt و sitemap و `/.well-known` · کشف زیردامنه از Certificate Transparency · پورت‌های رایج TCP · خزش هم‌مبدأ، فرم‌ها و اطلاعات جاوااسکریپت · کشف REST و GraphQL و OpenAPI · متدهای HTTP و صفحات خطا و پیکربندی نادرست · Open Redirect و Host Header · نشانه‌های تزریق (SQLi / NoSQLi / SSTI / LDAP / XPath) · پارامترهای کاندید SSRF · وضعیت ورود، CSRF، نشست و MFA.

فهرست کامل با تفکیک غیرفعال/فعال: [docs/modules.md](docs/modules.md)

## مجوز تست

فقط سیستم‌هایی را اسکن کنید که مالک آن‌ها هستید یا **مجوز کتبی** تست دارید. بررسی‌های فعال ترافیکی بیش از مرور عادی می‌فرستند و تست بدون مجوز ممکن است در کشور شما جرم باشد. پیش از اولین اسکن، [راهنمای ایمنی و مجوز](docs/fa/safety-and-authorization.md) را بخوانید.
