# Roadmap

Direction, not a commitment. Dates are deliberately absent.

## Under consideration

- **Optional live enrichment** — CVE, KEV and EPSS data for already-detected software versions, as an opt-in layer that is never required by the core.
- **External tool adapters** — optional connectors for specialist scanners, merged into the same finding model.

## Principles that will not change

- Detection, not exploitation.
- Hard time and request budgets on every scan.
- Honest coverage reporting; skipped is never clean.
- No invented evidence, no invented CVE identifiers.

See the [changelog](../CHANGELOG.md) for what has shipped.
