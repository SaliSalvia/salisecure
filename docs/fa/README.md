## اصطلاحات

- **بررسی غیرفعال (Passive):** فقط از چیزهایی استفاده می‌کند که یک بازدید عادی، یک پرس‌وجوی DNS، یک دست‌دهی TLS یا Certificate Transparency هم نشان می‌دهد.
- **بررسی فعال (Active):** درخواست‌های اضافه و هدفمند می‌فرستد. همیشه محدود و فقط برای تشخیص است.
- **یافته (Finding):** یک ضعف یا نشانه‌ی ضعف، همراه با شدت، اطمینان، شواهد و راه‌حل.
- **نشانه (Indicator):** یافته‌ای که هنوز تأیید نشده است. می‌گوید کجا را نگاه کنید، اما اثبات نیست.
